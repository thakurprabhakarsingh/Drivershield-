DriveShield AI Portfolio
========================

Files:
- index.html : main portfolio
- problem-*.html : clickable problem detail pages
- driver-monitoring.html
- vehicle-diagnostics.html
- live-location.html
- speed-monitoring.html
- smart-alerts.html
- emergency.html
- styles.css : shared design

IMPORTANT:
1. Open index.html in a browser.
2. Every Problem and Solution card is clickable/tappable.
3. To make feedback email work, replace YOUR_FORMSPREE_ID in index.html with your real Formspree endpoint/form ID and configure the recipient in Formspree.
4. The image URLs are remote Unsplash URLs, so internet is needed for those images.
